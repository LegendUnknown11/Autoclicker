# Autoclicker for Windows

[Download the latest installer](https://github.com/LegendUnknown11/Autoclicker/releases/latest/download/AutoclickerSetup.exe)

Autoclicker runs in the Windows notification area when its window is closed. F6 starts or stops clicking and F7 saves the cursor position. Both shortcuts can be changed in the app.

Install with Setup to receive future updates. Find **Check for updates** in **Advanced** or in the notification-area menu. When a new version is available, choose **Install and restart**. The app waits for clicking to stop before installing.

[Release notes and previous versions](https://github.com/LegendUnknown11/Autoclicker/releases)
